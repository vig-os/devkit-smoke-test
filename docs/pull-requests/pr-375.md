# [PR 375](https://github.com/vig-os/devkit-smoke-test/pull/375) fix(ci): drop the human-approval gate from the final release dispatch

## Summary

Removes the `Gate final release on human approval of release PR` step from the dispatch listener, matching the devkit template merged in [vig-os/devkit#1510](https://github.com/vig-os/devkit/pull/1510) — the copied file is **byte-identical** to `assets/smoke-test/.github/workflows/repository-dispatch.yml` at devkit `dev`, so the next scaffold deploy converges rather than reverts.

**Why this must land on `main` now:** the Main protection already requires zero approving reviews ([org-config#167](https://github.com/vig-os/org-config/issues/167)), and GitHub computes the polled review decision only when the base branch requires reviews — so the live gate can no longer resolve and **every final dispatch would time out un-unblockably** (a manual approval does not surface either). The listener runs from the default branch, hence the direct-to-main hotfix (precedents #345, #353).

The operative controls are unchanged: green smoke CI, and devkit's published-smoke-release validation at promote.

Refs: [vig-os/devkit#1506](https://github.com/vig-os/devkit/issues/1506)
