# [PR 439](https://github.com/vig-os/devkit-smoke-test/pull/439) chore(deps): drop leftover jupyter/science extras from the smoke payload

## Description

Drops the unused `dev`, `science` and `all` optional extras and the `[tool.uv] constraint-dependencies` block from `pyproject.toml`, then regenerates `uv.lock`. They are left over from the devkit Python template, which devkit retired in vig-os/devkit@a026454e. `dependencies = []` and the `dev` dependency group are unchanged.

Refs: #438

## Changes

- `pyproject.toml`: remove `[project.optional-dependencies]` and `[tool.uv] constraint-dependencies`
- `uv.lock`: regenerated with plain `uv lock` (uv 0.12.17, no `--upgrade`, so no unrelated pins move). The lock goes from 122 to 15 packages. The 3 platform-conditional `resolution-markers` entries also disappear: they came from the jupyter/numpy platform variants.
- `CHANGELOG.md`: Security entry under `## Unreleased`

## Verification

- `uv export --frozen --all-groups` no longer contains anyio, tornado, mistune, jupyterlab or soupsieve: every package behind the 14 open Dependabot alerts is gone
- `just lint`, `just test` and `just precommit` (full `prek run --all-files`) pass locally

## Notes

- Ownership: devkit never ships or overwrites this repo's `pyproject.toml`/`uv.lock` (they are in `PRESERVE_FILES`, and the deploy rsync runs without `--delete`), so a later deploy PR cannot revert this.
- The alerts and #433-#437 resolve once this reaches `main` with the next devkit release train.
- The issue's note about Renovate is outdated: smoke `renovate.json` already enables `pep621` on both `dev` and `main` (vig-os/devkit#1764).
